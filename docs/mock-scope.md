# モックの範囲

目的は一つ。チラシのグラデーションとふにゃふにゃした形を、デジタル庁デザインシステムの読みやすさを崩さずにサイトへ持ち込めるかを、ブラウザで動かして確かめる。CMS（EmDash）は使わない。ただし HTML/CSS は捨てずに、あとで Astro の部品へそのまま移す。

## 置き場所

| パス | 中身 |
|---|---|
| `mock/index.html` | トップページ（1ページに全セクション） |
| `mock/exhibitor.html` | 出展者の詳細ページ（CMS のリッチテキストの見え方を確かめる） |
| `mock/mock.js` | モック確認用の切り替えパネルと、一時停止ボタンの処理だけ |
| `css/tokens.css` / `css/style.css` | デザインシステムに、ブランド表現の部品を足す（モック専用にせず本番でも使う） |
| `assets/logo.svg` | `docs/2024チラシ.ai` の3ページ目から取り出したロゴ（ベクター） |
| `assets/illust/*.webp` | チラシに埋め込まれていた線画（ラスター。透過 PNG から WebP に変換） |

## 作るもの（細かく作る）

| 場所 | 中身 | 確かめること |
|---|---|---|
| ファーストビュー | チケット型の枠（切り欠き・ミシン目・半券）、ロゴ、キャッチコピー、日付・時間・会場、blob、線画 | チラシに見えるか。375px で崩れないか |
| お知らせ | 一覧3件 | 既存の部品のまま |
| 出展者一覧 | カード30件。写真あり/なし、長い店名、カテゴリのラベル | CMS の入力の揺れで崩れないか |
| タイムテーブル | ステージ企画5件程度の表 | 表の読みやすさ |
| 協賛・広告 | ランク別のロゴのグリッド（横長・正方形のロゴ混在）と、バナー広告枠1つ | ロゴの形がばらばらでも揃って見えるか |
| 開催情報 | 日時・会場・地図へのリンク | 既存の部品のまま |
| 出展者の詳細 | 写真、紹介文（見出し・段落・リスト・リンク） | リッチテキストの CSS |

## 動き（7パターンを本番と同じ実装で入れる）

| # | パターン | 実装 | 場所 |
|---|---|---|---|
| 1 | blob がゆっくり漂い、形がふにゃふにゃ変わる | `border-radius` と `transform` の `@keyframes`（20秒前後） | ファーストビュー、セクション背景 |
| 2 | グラデーションがゆっくり流れる | `@property` で登録した角度を回す。補間は `in oklch` | 見出しの下の装飾線、フッターの上線 |
| 3 | ホバーで縁がふにゃっとする | `:hover` / `:focus-within` で `border-radius` を変える | 出展者カード |
| 4 | 線画が振り子のように揺れる | `rotate` の `@keyframes`、`transform-origin` を吊り下げ点に | 風船・電球・ガーランド |
| 5 | セクションの境目が波線 | `mask` と `radial-gradient` | 背景色が変わるセクションの上下 |
| 6 | チケット型 | `mask` で切り欠き、`border-style: dashed` でミシン目 | ファーストビュー |
| 7 | スクロールで blob が膨らむ | `animation-timeline: view()`。`@supports` で囲む | セクション背景の blob |

全体の約束:
- `prefers-reduced-motion: reduce` のときは全部止める。画面右下に一時停止ボタンを常に出す（WCAG 2.2.2）。
- 文字の背後の blob は、白文字とのコントラストを大きい文字で 3:1、本文で 4.5:1 以上に保つ。
- 主要ボタンは白のまま（DESIGN.md の「ボタンにグラデーションを使わない」を守る）。
- JS はモック確認パネルと一時停止ボタンだけ（本番に残るのは一時停止ボタンの数行）。

## 粗くてよい・作らないもの

- 下層ページ（アクセス・FAQ・お問い合わせ）、ページ遷移の演出、管理画面
- 文章（仮の文）、出展者の写真（仮の画像）、協賛のロゴ（仮の SVG）
- 出展者のカテゴリ絞り込み（要否は判断待ち。要るなら JS が増える）
- 線画の「ぷるぷる震え」（SVG フィルタ）と、カーソル追従の blob

## 確認パネル（モック専用、本番では消す）

好みで決める項目を、画面上で切り替えて比べられるようにする。
- 動きの量: 標準 / 控えめ / なし
- blob の量: 少なめ / 多め

## 終える条件

- 375px と 1280px の両方で、横スクロールが出ず、文字が読める
- 一時停止ボタンと `prefers-reduced-motion` で全部止まる
- 転送量: JS 20KB 以下、HTML+CSS 50KB 以下（brotli 後）、トップの画像合計を計測して報告する
- Tab キーだけで全部操作でき、フォーカスが見える

ここまで作ったら止めて、好みで決める項目をまとめて聞く。
