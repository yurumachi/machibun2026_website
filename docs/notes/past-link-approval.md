# 前の年との関連付けに承認が要るかどうか

まちぶんの grill-with-docs（2026-10-14）の途中で出た、別の学園祭の団体管理 app の相談をまとめたメモ。まちぶん自体の決定ではない。

## 判断の軸

前の年の記録と関連付けたとき、公開していない情報が見えるようになるか。見えるようになるなら、関連付けは「見る権利を渡すこと」なので、誰かが確かめる。見えるのが公開済みの内容だけなら、確かめなくてよい。

| | 関連付けで見えるもの | 承認 |
|---|---|---|
| まちぶん | 前の年に公開した紹介文・写真 | 不要（もともと誰でも見られた） |
| 団体管理 app | メンバー情報・調理工程などの非公開情報 | 必要 |

## 団体管理 app での作り方の案

1. 関連付けに「申請中」と「承認済み」の状態を持たせる。
2. 非公開の情報は、承認済みの関連付けがあるときだけ見せる。公開してよい情報は申請中でも見せ、承認待ちのあいだも入力を進められるようにする。
3. 承認は、前の年の代表者のメールに確認リンクを送り、押されたら承認済みにする。情報の持ち主が許可する形で、委員会の手間も要らない。代表者に連絡がつかないとき（卒業など）だけ、委員会が承認する。

## 情報の種類で扱いを分ける

- 調理工程: 個人情報ではなく、団体の非公開情報。引き継ぐ価値が高いので、承認後に見せてよい。
- メンバー情報: 個人情報。前の年の名簿は今年のメンバーと違うことが多い。承認後でも前の年の名簿は見せず、今年の分を入れ直してもらうほうが安全。
