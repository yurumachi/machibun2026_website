# 画像は R2 ではなく KV に置く

出展者の写真や協賛のロゴなど、CMS で扱う画像は、まちぶんの Cloudflare アカウントの KV に置く。EmDash の標準は R2 だが、このアカウントで R2 を有効にすると支払い方法の登録を求められ、無料枠を超えたときに請求が起きうる。KV は支払い方法なしの無料プランで使え、上限を超えると請求ではなく失敗になる。EmDash は置き場所の処理を差し替えられるので、KV 用の処理（`site/src/storage/kv.ts`）を自分たちで持つ。

## Considered Options

- このアカウントで R2 を有効にする: 支払い方法の登録と、上限のない請求を避けたいので採らなかった。
- 別のアカウントの R2 や外部の S3 互換ストレージにつなぐ: このアカウントのものは、このアカウントにまとめておきたいので採らなかった。
- 画像を repo に入れる: 出展者が自分で写真を上げられなくなり（ADR 0001）、人が写った写真が git の履歴から消せなくなるので採らなかった。
- D1 に置く: 1件 2MB までで、写真を縮めてから入れる必要があるので採らなかった。

## Consequences

- KV の無料枠（保存 1GB、書き込み 1000回/日、読み出し 10万回/日）に収める。1件は 25MiB まで。
- KV は書き込みが各地に行き渡るまで 60秒ほどかかることがあるので、上げた直後の画像が別の場所から一時的に見えないことがある。
- 画像は Worker を通して返すので、表示するたびに Workers の無料枠（10万リクエスト/日）を使う。トップページの写真は、Astro の画像変換（本番では Cloudflare Images の `IMAGES`）も通る。当日のアクセスで足りるかは、ステージングで測ってから判断する。
- EmDash を上げたときに置き場所の約束（`Storage` の型）が変わったら、`kv.ts` を合わせて直す。
