# 出展者は年ごとに別のものとし、前の年とは「前回の出展」の参照だけでつなぐ

同じ団体でも、名前や代表者は年によって変わる。そのため、年をまたいで続く「団体」は持たず、出展者・出演者を年ごとに新しく作る。前の年とは、出展者本人がフォームで選ぶ「前回の出展」の参照だけでつなぐ。参照してコピーできるのは、前の年に公開した紹介文と写真だけにする。もともと誰でも見られたものなので、間違った出展を選ばれても害がない。このため運営の承認は要らず、関連付けの手間が運営に回らない。

## Considered Options

- 年をまたぐ「団体」を持ち、運営が年ごとの出展とつなぐ: 名前や代表者が変わったときの判断と、つなぐ作業が運営に残るので採らなかった。

## Consequences

- 協賛は「前回」の参照も持たず、年と企業名で検索して過去を見る（企業名はほとんど変わらないため）。
