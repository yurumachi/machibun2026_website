# 連絡先は記事ではなくプラグインの保存場所に置き、管理者だけに見せる

連絡先は CMS で扱いたいが、実行委員には見せない。EmDash の権限はサイト全体で一律で、項目ごとや記事の種類ごとに読める人を絞れない。公開しない記事にしても、Contributor 以上なら誰でも読める。そこで連絡先は、自作のプラグインの保存場所に置く。読み出しも、プラグインの入口で管理者の役割（Admin）を確かめたときだけにする。この保存場所は通常の API からも、snapshot からも読めない。

## Consequences

- 連絡先は、自動ではなく管理者が手で消す。EmDash のバックアップにも残るので、それより前のバックアップも管理者が手で消す。
- 閲覧の記録は残せない（EmDash に読み取りのフックがない）。
