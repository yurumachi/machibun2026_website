# 出展者・出演者・協賛は EmDash のアカウントを使わず、編集用の鍵と専用フォームで入力する

出展者・出演者・協賛には、自分の分を自分で入力してもらう。そのために、一件ごとに編集用の鍵（URL とパスワード）を渡し、サイトの中の専用フォームから下書きを書き換えてもらう。公開するのは、運営が確認してからにする。EmDash の利用者にしない理由は、下書きを書ける最低の役割（Contributor）でも、他の出展者の下書きまで全部読めてしまうからだ。もう一つ、ログインに passkey かメールが要るため、年に一度だけ入力する外部の人には重い。

## Considered Options

- EmDash の Contributor として招待する: 他人の下書きが見えるので採らなかった。
- 運営が申込フォームから転記する: 運営の手間が大きいので採らなかった。

## Consequences

- 「その一件だけ書ける」という制約は EmDash に任せられないので、プラグインの中で自分たちで守る。
- 鍵を団体の中で共有されても気づけず、誰が直したかも一件単位でしか分からない。お祭りの出展情報なら、ここまでで足りると判断した。
